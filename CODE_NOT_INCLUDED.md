# Code not included

This public repository contains Farolero’s agreement, operating model, captured evidence, and project limits. It does not contain source code. The code is scheduled to open during the judges’ review period under the review-only terms in [`LICENSE`](LICENSE), which allow reading and cloning for evaluation, not modifying the code.

Until that review period opens the code, this repository can be reviewed through its documented rules and the supplied test record. The walkthrough in [`docs/HOW_IT_WORKS.md`](docs/HOW_IT_WORKS.md) is explanatory; it is not a runnable transcript. [`docs/EVIDENCE.md`](docs/EVIDENCE.md) distinguishes the captured test output from behavior that still needs a fresh run after the kernel pin is fixed.

## Código no incluido

El código está previsto para abrirse durante el periodo de revisión de los jueces bajo los términos de solo revisión de [`LICENSE`](LICENSE), que permiten leer y clonar para evaluar, no modificar el código.

Hasta que se abra el código, este repositorio puede revisarse mediante las reglas documentadas y el registro de pruebas suministrado. El recorrido de [`docs/HOW_IT_WORKS.md`](docs/HOW_IT_WORKS.md) es explicativo, no una transcripción ejecutable. [`docs/EVIDENCE.md`](docs/EVIDENCE.md) distingue la salida capturada de las conductas que todavía necesitan una corrida nueva después de fijar el kernel.
